# result-view
A table tennis result view for showing results

## Docker build:

Run `ng build --configuration production --base-href ./ --progress false` to build app.
Run `docker build . -t holzleube/result-view:1.x` to build image.

[DockerTags](https://hub.docker.com/r/holzleube/result-view/tags)

## Development server

Run `npm start` for a dev server on `http://localhost:4202/`. The app will automatically reload if you change any of the source files.

## Testing

Run `npm test` to execute the Vitest unit tests and `npm run e2e` to run the Playwright end-to-end tests.

## Formatting

Run `npm run format` to format the code with prettier.
